4. Get the map

To repaint an existing map, use File → Export terrain to PNG in the VCMI map editor, open both PNG files here, then import the saved PNG back with File → Import terrain from PNG.

Only the terrain grid is sent to the server. Towns, heroes and objects are placed afterwards in the VCMI map editor.
